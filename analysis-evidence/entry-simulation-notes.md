## trader-entry: breakout ka exact confirmation

Is module ka kaam position lena nahi, completed candle par signal record karna hai. `check SYMBOL` ek snapshot hai; `watch SYMBOL` process chalata hai; `watchlist` scanner ke `hits[].symbol` ko ek baar sequentially evaluate karta hai. `watchlist` continuous multi-symbol subscription nahi hai. Default `setup=orb`, opening range 15 minutes, interval `5m`; `1m` bhi supported hai. Long/buy aliases accepted; sell/short runtime par refused. Common flags: `--setup orb|level`, `--or-minutes N`, `--interval 5m|1m`, `--level PRICE`, `--min-volume-x X`, `--side`, `--config`, `--now`, `--offline`. `check` adds `--write [PATH]`, `--json`; `watch` adds `--every 30`, `--until HH:MM`, `--out trader/entry.json`; watchlist adds `--watchlist trader/watchlist.json`, `--json`. Default New York entry window 09:45–15:30 hai. Code 2026/2027 NYSE holidays aur three early-close dates hardcode karta hai. Weekend closed; unknown years ke holidays automatically fetch nahi hote. Early close par default cutoff 12:30 ho jaata hai. Time conversion manually US DST rule calculate karti hai, operating-system timezone se independent. `--now` without offset New York wall time hai; ISO offset/Z absolute time hai. References: `trader-entry/entry.py:64`, `:74`, `:119`, `:159`, `:201`, `:397`.

Query2 pehle; HTTP429 par five-second wait aur one retry, phir query1; 5xx par fallback. Request timeout20s. JSON/gzip file ya directory of symbol files offline supported. Level setup mein threshold user level, eligible slots0 onward; same time limits apply. Optional volume condition `barVolume/avgVol >= min_volume_x`. **Implementation limit:** all range slots present hona required nahi: at least one range bar enough hai; `opening_range.complete` clock se set hota hai, actual `bars==of` se nahi. Volume average bhi available range bars par hai. References: `trader-entry/entry.py:482`, `:488`, `:501`, `:506`.

Code earliest qualifying candle re-finds each check; later closes daily trigger replace nahi karte. Status `waiting`, `triggered`, `expired`, `no-data`; phases pre-open/forming/open/after-cutoff/after-close/closed. Already-triggered snapshot market-close ke baad bhi triggered rehta hai. Return code `check`:0 only triggered,1 otherwise; `watchlist`:0 if any trigger. References: `trader-entry/entry.py:518`, `:534`, `:807`, `:911`.

## trader-exit: fixed stop/target plan

`exit.py plan` default `trader/entry.json` read karta hai; `--from PATH` alternate, ya `--symbol --entry` manual facts. File status triggered required unless explicit `--entry` se plan ahead kar rahe hain; overridden entry old trigger time/index automatically inherit nahi karta. `--symbol` aur `--from` together refused. Both command flags aur imported side long-only checked. `show --plan trader/plan.json` existing plan displays, trade monitors nahi karta. References: `trader-exit/exit.py:527`, `:565`, `:675`, `:694`.

Entry aur OR endpoints Decimal half-up cents tak round hote hain. Default ORB stop midpoint; level setup ko explicit stop chahiye. Raw long stops:

- `or-mid`: `(H+L)/2`; `or-low`: `L`.
- `price:X`: `X`; `pct:X`: `E*(1-X/100)` with0<X<100.
- `atr:K`: `E-K*ATR`.

Final stop cents par floor hota hai, entry se door/down. `risk=E-S`. Risk `E*0.0005` se kam reject; zero/negative stop, stop≥entry, target≤entry reject. Default target2R; arbitrary positive `qR` accepted, target `half_up_cent(E+q*risk)`. Explicit price target half-up cent; reward:risk `(T-E)/risk` two decimals half-up. Requested R target mein `target_r` requested multiple retain hota hai; actual ratio cent rounding se slightly differ kar sakta hai. References: `trader-exit/exit.py:196`, `:234`, `:251`, `:270`, `:305`, `:313`, `:319`.

ATR textbook Wilder-smoothed ATR nahi: simple arithmetic mean of last up-to14 true ranges hai. Session first bar `TR=H-L` (overnight gap excluded); subsequent `TR=max(H-L,abs(H-prevClose),abs(L-prevClose))`. Minimum3 closed session bars, maximum14 used; fewer14 notice. Bars entry slot tak clipped if entry_bar known. **Limit:** only entry_time given, entry_bar absent ho toh function time ko slot cutoff mein derive nahi karta; filter chart data-time/explicit `--now` tak hota hai, potentially intended entry ke baad ke bars use ho sakte hain. References: `trader-exit/exit.py:442`, `:469`, `:584`.

Flat-by default config15:55, early-close default12:55; explicit flat-by at/after session close refused. Entry-time≥flat-by refused. Config `min_reward_risk=1.0` se lower ratio warning only hai; planner reject nahi karta, enforcement downstream trader-risk par delegated hai. Dated-old plan warning only. Planner stop ko later enforce/move nahi karta. References: `trader-exit/exit.py:505`, `:595`, `:611`.

`--write [PATH]` default `trader/plan.json`: `created_by,symbol,side,date,setup,entry,entry_time,entry_bar,interval,opening_range,stop,stop_rule,stop_label,target,target_r,target_label,risk_per_share,reward_risk,flat_by,stop_detail,created_at,note`; ATR plans add `atr,atr_bars`. JSON stdout adds warnings, saved plan does not. TSLA fixture E364.18,H362.18,L354.47: midpoint358.325 floors358.32; risk5.86;1R target370.04; default2R375.90. ## trader-timemachine: conditional bar-bootstrap aur historical replay

`run` loads `--plan trader/plan.json`, or manual `--symbol --entry --stop --target --entry-time [--date]`. Defaults10,000 replays, seed19, window2 bars; `--until` optional; `--offline`, `--now`, `--json`, `--write [PATH]`. `chart --from [PATH]` saved run ka17-row ASCII fan displays; without from recomputes. Replays1–1,000,000, window0–10. Independent simulator buy **and sell** supports, unlike entry/exit. Only5m plans; buy S<E<T, sell T<E<S. Entry close on5m grid, entry_time/index mutually consistent, slot0–76; minimum one future bar required. References: `trader-timemachine/timemachine.py:505`, `:531`, `:679`, `:895`, `:912`.

Yahoo nominally one60d5m chart request; retries/fallback extra requests possible. Data parser keeps full OHLC, on-grid, completed09:30–16:00 bars; completion clock is earlier of provided now and Yahoo regularMarketTime. Pool sessions strictly before plan date, exactly all78 slots; gaps/half-days excluded; at least20 full sessions required. Actual dates/count in result authoritative—`60d` label is request parameter, not a proof of exactly60 calendar days of retained fixture history. Entry bar must actually exist; entry outside its high/low±one cent warns only. Early-close plan ends13:00 by hardcoded three-date table. **Saved plan.flat_by is retained but unused for default horizon**: pass `--until 15:55` explicitly. References: `trader-timemachine/timemachine.py:188`, `:203`, `:271`, `:318`, `:697`, `:714`, `:719`.

Pool slot i stores `(O_i,H_i,L_i,C_i)/C_(i-1)` for every historical full session, i1–77. Each replay starts at planned E, and for each future slot i draws time-slot `clamp(i+randint(-window,window),1,77)` then uniform random historical whole-bar tuple from that slot. Window0 uses exact slot. Current price p scales sampled high/low/close; sampled open is unpacked but unused. Stop checked before target; candle touches both => stop. Sell logic mirrored. Once first outcome known it stays fixed, **but underlying path continues simulating till horizon**. References: `trader-timemachine/timemachine.py:335`, `:349`, `:355`, `:366`.

Odds counts/N: target, stop, neither. Green=target outcome OR neither with favorable final close; stopped path later recovering does not become green. Per-path R is target-distance/risk, −1 stop, otherwise signed terminal move/risk. Thus gap-through-stop always −1R; no fill slippage/commissions modeled. Median/p5/p95 terminal prices describe continued underlying paths even after exit, not distribution of account returns. Percentile uses sorted index `int(q*N)`, capped N−1, no interpolation. AverageR rounded3 decimals, probabilities4 decimals. References: `trader-timemachine/timemachine.py:345`, `:383`, `:387`, `:416`.

First up-to160 paths saved; fan separately simulates exactly2,000 paths with same seed and5/25/50/75/95 percentiles. Therefore fan terminal quantiles can differ from primary10,000 summary. Histogram24 bins spans primary p1–p99; values outside excluded, counts need not total N. Seed plus data/plan/window/horizon/replay count fixes reproducibility. References: `trader-timemachine/timemachine.py:89`, `:393`, `:409`.

History reruns ORB per historical full session: first post-range close beyond high/low up to horizon enters; rounded close entry, rederived stop, same targetR; subsequent bars stop-first; neither marked at horizon. History mean averages already two-decimal per-trade R. Non-ORB skips history. Auto stop infers midpoint/far edge if matches today's range within0.005, else fixed stop-distance percentage. ATR/price/other stop rules likewise become percentage in history. **“Same rule” qualification:** history does not reproduce volume filter, configurable no-entry-before/after, ATR calculation, or entry-day time conditioning. It can enter on horizon candle and record zero remaining-bar result. References: `trader-timemachine/timemachine.py:429`, `:451`, `:594`, `:728`.

Verdict uses conditional target share `w=p_target/(p_target+p_stop)` against breakeven `b=1/(1+R_target)`; d=w−b. abs(d)<0.05: coin flip at1R, break-even otherwise; <0.15 lean; otherwise strong; sign chooses target/stop. No side hit => separate message. Neither>40% note; non-neutral lean and opposing meanR sign => extra note. This ignores neither in headline, intentionally; it is a heuristic classification, not significance test/confidence interval. References: `trader-timemachine/timemachine.py:631`, `:642`, `:665`.

Saved `timemachine.json` contains metadata,data/drop counters/short sessions,normalized plan,mc,history,verdict,verdict_notes,warnings,note. mc includes probabilities,terminal percentiles,meanR,bands,sample_paths,hist,pool dates,times; history includes counts/rule/trade records. `--json` stdout omits sample_paths, saved output includes them. Source `offline` correctly labeled. References: `trader-timemachine/timemachine.py:738`, `:870`, `:880`.

History33 triggers:13 target,15 stop,5 neither; meanR−0.062. Tests verify seeds, frozen path hashes, short-session exclusion, plan refusals, shorts, horizon, R-weighted verdict and retry mocks. References: `tests/test_timemachine.py:88`, `:104`, `:112`, `:161`, `:228`, `:323`, `:385`, `:395`, `:468`.

Methodology inference: bar draws independently resample historical time buckets, preserving within-bar high/low/close relation but not cross-bar/day regime continuity. No conditioning on current news/volatility/volume and no overnight, halt, order-book, partial fill, fees, spread, market-impact or statistical uncertainty model appears in these algorithms. “Every possible outcome” in SKILL introduction is promotional wording: actual output is finite random replays plus limited historical ORB rule samples.
