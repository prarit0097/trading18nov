## trader-scanner: universe se rule-matching watchlist

**Purpose aur interface.** `scan.py` ke teen subcommands hain: `universe`, `daily`, `orb`. Yeh brokerage order, sizing ya risk approval nahin karta. `universe` default `trader/universe.txt` likhta hai; `daily` aur `orb` dono default `trader/watchlist.json` ko overwrite karte hain. Isliye daily shortlist preserve karni ho to alag `--out` dena hoga. JSON stdout aur saved file identical nahin: stdout mein extra `counts` aur elapsed `seconds` hain. `--no-write` file mutations rokta hai; `--json` apne aap writing nahin rokta. Sources: `trader-scanner/scan.py:840`, `:883`, `:898`, `:904`, `:986`, `:993`, `:1030`.

**Universe algorithm.** Nasdaq Trader ke `https://www.nasdaqtrader.com/dynamic/SymDir/nasdaqlisted.txt` aur `otherlisted.txt` download hote hain. Pipe-delimited headers parse hote hain, creation timestamp nikala jata hai, duplicate symbols dictionary se collapse hote hain aur result alphabetically sorted `SYMBOL|Name` lines banta hai. Filtering order meaningful hai: Test Issue aur ETF exactly `N`, NextShares absent ya `N`; plain uppercase ticker pattern; `.U/.W/.R` rejection; hard-exclusion name rules; recognized common/ordinary/ADR/beneficial-interest/partnership-unit names inclusion; residual unit/right/bond/preferred names exclusion; remaining names inclusion. Isko strict “sirf operating-company common equities” filter kehna galat hoga: docs closed-end funds aur partnership units bhi acknowledge karte hain. Sources: `scan.py:82`, `:421`, `:446`, `:465`; `trader-scanner/SKILL.md:53`, `:72`.

**Daily inputs aur math.** Yahoo `/v7/finance/spark?symbols=...&range=3mo&interval=1d`, maximum 20 symbols/request. Default floors: price $5 aur metadata `regularMarketVolume` 1,000,000 shares. Price metadata absent ho to latest completed close fallback hai; volume absent ho aur positive floor ho to stock reject hota hai. Minimum 30 completed daily closes required. Null closes aur future-dated bars drop hote hain; current ET date ka bar session close tak excluded hota hai, including configured early close. Daily duplicates mein later encountered value wins. During-session liquidity metadata today's-so-far ho sakti hai, jabki setups previous completed daily close se honge. Sources: `scan.py:274`, `:485`, `:498`, `:542`, `:894`; `SKILL.md:79`.

Five rules ke exact formulas, oldest-first closes `c` ke liye:

- `breakout_20d`: `c[-1] > max(c[-21:-1])`, intraday high breakout nahin.
- `bull_flag`: `(c[-6]/c[-16] - 1) > 0.10` aur `(max(c[-5:])-min(c[-5:]))/c[-1] < 0.05`.
- `reclaim_ma20`: `c[-2] < mean(c[-21:-1])` aur `c[-1] > mean(c[-20:])`.
- `oversold`: Wilder RSI(14) `<30`; initial average first 14 changes, phir recursive `(old*13 + new)/14`. Zero average loss par RSI 100 return hota hai.
- `oversold_bounce`: previous close-sequence RSI `<30` aur last close previous se higher; current RSI ka 30 cross karna required nahin.

Daily hits descending `price*volume`, tie mein symbol se sorted hain. Hit shape: `{symbol,setups[],price,close_date,rsi,volume}`; prices 2 decimals, RSI 1 decimal. Document: `{created_by,created_at,mode,as_of,universe,scanned,failed,source,filters,note,hits}`; offline mode additionally `offline`. `as_of` most-common latest bar date hai, tie par later date. Sources: `scan.py:516`, `:569`, `:572`, `:898`.

**ORB exact process.** Fixed 5-minute bars, configurable opening range default 15 minutes: 09:30/09:35/09:40 bar starts. `--or-minutes` 5–120 aur multiple of 5 hona chahiye. First eligible breakout bar 09:45–09:50 hai, isliye default earliest run 09:50 ET. Every completed grid slot 09:30 se cutoff tak present hona compulsory hai; missing/null/off-grid/in-progress bar chart ko unusable bana sakta hai. Pre/post-market aur closing print excluded hain. Stage 1 spark close-only data: range ke highest close ke `>=` koi later completed close candidate banata hai. Stage 2 v8 chart se real range highs/lows: first later close **strictly above** maximum range high hit hai; intrabar wick alone hit nahin. Hit time bar close time hai. Range low minimum opening-range low hai. Sources: `scan.py:584`, `:610`, `:622`, `:629`, `:647`.

Stage 1 price floor last completed close; volume available bar volumes ka sum, otherwise metadata volume. Default min volume 0. Candidate ranking last close × volume so far; default maximum 200 chart confirmations, `--max-confirm 0` unlimited. Skipped candidates `unconfirmed` mein counted aur human output `PARTIAL` kehta hai. Offline data existing series se confirm hota hai, extra network stage nahin. Hits chronological breakout time, then symbol order mein hain. Hit shape: `{symbol,setups:["orb"],price,at,bar_start,bar_index,or_high,or_low,pct_over}`; envelope mein `unconfirmed`, `or_minutes`, `interval` extra. Sources: `scan.py:686`, `:705`, `:713`, `:729`, `:733`, `:980`, `:986`, `:1006`.

**Clock, network aur limits.** ET DST calculation explicit hai, machine timezone independent; `--now` naive datetime New York maana jata hai, offset/Z supported. Weekend aur hardcoded **2026–2027** NYSE holidays/early closes supported hain; calendar future years auto-refresh nahin hota. Default ORB cutoff actual now, `--at HH:MM` explicit cutoff, `--until` overrides config `no_entries_after`, otherwise 15:30. Future cutoff, pre-first-close, closed market aur expired entry-window errors scan write se pehle raise hote hain. After-close replay explicit `--at` se supported hai. Live historical request >6 days old reject hoti hai; today `1d`, otherwise `5d` range. Sources: `scan.py:96`, `:150`, `:178`, `:647`, `:945`, `:964`.

Yahoo unofficial hai. query2 first, 429/5xx/network failure par query1 fallback; 429 seen ho to 5-second wait aur ek extra round; other HTTP 4xx final, JSON error body caller parse kar sakta hai. HTTP timeout 20s; Nasdaq downloads 60s; pause default 0.3s. Offline folder/single spark/v8/bundle JSON aur `.json.gz` accepted. Symbol source precedence explicit `--symbols`, `--watchlist`, offline symbols, universe file; deduplication aur `--limit` follow karte hain. `--show 50` console display limit hai, saved hits ka cap nahin. Exit 0 any hits/kept universe, 1 none/handled ScanError/interrupt; generic malformed filesystem/data exceptions sab centralized catch nahin hote. Sources: `scan.py:229`, `:235`, `:371`, `:747`, `:771`, `:1034`, `:1072`.

Docs weekly universe refresh, pre-open daily, after-09:50 ORB suggest karte hain; scheduler implement nahin hai (`SKILL.md:143`). Tests rule filters, DST, fallback/backoff, incomplete/half-day bars, two-stage confirmation, missing slots, capped most-traded selection, CLI writing aur historical replay cover karte hain. 234-symbol fixture test 233 fetched/231 usable/42 hits ka regression hai, market-wide performance proof nahin. Sources: `tests/test_scanner.py:55`, `:171`, `:258`, `:318`, `:460`, `:492`.

Per ticker Yahoo headline RSS, Yahoo v8 chart `range=1d&interval=5m`, aur per SEC form company Atom feed fetch hota hai; default form `8-K`, feed count 10 hardcoded main default. Sources: `news.py:160`, `:308`.

**Processing.** RSS item includes `id=rss:<guid-or-link>`, source, kind, ticker, title, description summary, link, parsed publication time. Important set `1.03,1.05,2.02,2.04,2.06,3.01,4.02,5.01,5.02` hai; 9.01 exhibit label title se excluded. Ten regex categories: earnings, analyst, legal, deal, capital, people, risk, halt, regulatory, macro. Yeh keyword classification hai, financial sentiment/causal inference model nahin. Own feed ticker automatically touches; additional tickers `(TICKER)`, `$TICKER`, exchange notation ya known company name se detect hote hain. Dedupe same id, same link, ya normalized same title+date par merge karta hai aur touches combine karta hai. Window default 48h; `--hours` changes, `--all` previously seen include karta hai. Filter future tolerance **now+10 minutes** hai; missing timestamp window filtering bypass karta hai aur now-based ordering milti hai. Newest-first sort. State fingerprint SHA1(id) first16 hex; retention 30 days. Important caveat: `remember(items,...)` all collected/deduped items remember karta hai, sirf displayed window items nahin; therefore baad mein wider window bina `--all` older collected stories automatically surface nahin karegi. “Never repeats” doc wording retention/state continuity ke scope mein hai. Sources: `news.py:354`, `:375`, `:411`, `:428`, `:523`, `:534`.

Price move metadata `regularMarketPrice` vs `chartPreviousClose` otherwise `previousClose`; percent `(price/prev-1)*100`, 2 decimals. `MOVING` absolute rounded percentage >= default3; price timestamp separately shown, pinned `--now` price metadata ko historical reconstruct/filter nahin karta. JSON envelope `{checked,moves[],items[],notes[]}`, moves include ticker,price,prev_close,pct,time,moving; items also touches,tags,new aur filing extras. Dates ISO; human output ET. State `{ciks,seen,last_check}` default `trader/state/news.json`; `--dry-run` suppresses state write. Exit0 at least one shown unseen item, else1, no tickers2. Notes/feed failures alone dedicated error exit nahin banate. Sources: `news.py:291`, `:438`, `:481`, `:527`, `:542`.

Agent instructions article/filing open karke verify karne, paywall limitation kehne aur brief likhne ko bolti hain; Python article body fetch/summarize nahin karta. `/loop 15m` ya morning schedule host-side suggestion hai. Sources: `trader-analyst/facts.py:53`, `:79`, `:92`, `:470`.

**Quarter building.** Only `facts.us-gaap` concepts; revenue fallback ordered seven tags, plus cost-of-revenue, gross profit, operating income, net income and diluted EPS concepts. Preferred units `USD` / `USD/shares`, absent preferred unit par first available unit use hota hai. Duration facts accepted from 10-Q/10-K/20-F/40-F (amendment suffix stripped). Same start/end period: latest `(filed,accn)` value wins, earliest filing ke fiscal year/period labels retained. 80–100-day intervals quarters, 350–380-day full years. Q4 = annual minus exactly three contained quarters, only if year-end quarter already absent; derived EPS approximate. Later fallback concepts only missing end dates fill karte hain, earlier concept values overwrite nahin karte. Sources: `facts.py:62`, `:131`, `:141`, `:166`, `:195`.

Banks automatically zero margin set nahin hote; unavailable components null remain. Sources: `facts.py:213`, `:223`, `:235`.

Stale note latest report period > latest facts end by >20days par. Sources: `facts.py:256`, `:276`, `:281`, `:294`, `:519`.
