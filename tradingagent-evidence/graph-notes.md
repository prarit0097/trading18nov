## 2. Parallel analysts ka isolation aur tool-loop control

Har analyst apna compiled subgraph hai. Input schema `AgentState` ho sakta hai, lekin output schema sirf us analyst ka report field expose karta hai. Isliye Market Analyst ke tool calls News Analyst ke chat history mein merge nahi hote; parallel branches same state key write bhi nahi karti. Parent ko market/news/fundamentals/sentiment reports milte hain, unke raw private tool transcripts nahi. [[tradingagents/graph/setup.py:53]]

Tool-using analyst `agent → tools → agent` repeat karta hai. `AIMessage.tool_calls` present ho to `ToolNode` invoke hota hai; otherwise report complete aur subgraph END. `max_tool_rounds` tool-calling messages ki count hai, individual tool calls ki count nahi: ek response mein multiple calls ek round hain. Limit par extra wrap-up turn chalta hai aur uske baad unconditional END hai. [[tradingagents/graph/setup.py:48]] [[tradingagents/graph/setup.py:70]]

Wrap-up mein model ko tools bind nahi kiye jaate. Purane calls aur ToolMessages plain text mein rewrite hote hain, taaki provider unbound-tool history refuse na kare. Report missing data explicitly batane ko kehta hai. Constructor unsafe combination `2 * max_tool_rounds + 2 >= max_recur_limit` reject karta hai. Yeh runaway loops ka operational guard hai; report factual completeness ki guarantee nahi. ## 4. Research debate se trade proposal

Bull Researcher reports ko growth, competitive advantages aur positive indicators ke favour mein argue karta hai; Bear risks, weaknesses aur negative indicators par counter-case banata hai. Dono prior debate aur opponent response read karte hain, apna labelled argument history mein append karke count increment karte hain. Yeh extra external research calls nahi: researcher functions plain `llm.invoke(prompt)` use karte hain. Router `count >= 2 * max_debate_rounds` par Research Manager bhejta hai; otherwise Bull-labelled latest response ke baad Bear, aur fallback Bull. Thus rounds language ka practical matlab har side ke configured turns hai. Research Manager debate history judge karke five-tier recommendation, rationale aur strategic actions produce karta hai. Prompt conflict ko automatic Hold banane se rokta hai, lekin balanced/thin evidence par Hold allow karta hai.
