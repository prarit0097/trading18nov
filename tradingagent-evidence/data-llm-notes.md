## Failure ka matlab

Three behavioral types hain: `NoMarketDataError` usable data absent/stale, `VendorUnavailableError` request failed/throttled, aur `VendorNotConfiguredError` missing configuration. Router sab par chosen next vendor try karta hai. Entire chain ke baad unavailable vendor ho to `DATA_UNAVAILABLE`; only clean no-data answers par `NO_DATA_AVAILABLE`, instrument ko invalid declare karna zaroori nahin. Generic failure plus no-data bhi unavailable ban jaata hai. Sirf configuration/untyped errors bache to core category first error raise karti hai, macro/prediction optional categories sentinel mein degrade hoti hain. Sentinels model ko numbers fabricate na karne ki explicit instruction dete hain, deterministic enforcement nahin. [[tradingagents/dataflows/errors.py:1]] [[tradingagents/dataflows/router.py:178]] [[tradingagents/dataflows/router.py:257]]
