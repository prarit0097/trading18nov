# Implementation contract

Python standard library only, Python >=3.11. Package `crypto_skills`. All commands work in explicit `--workspace` directory; state under `trader/`. No live order endpoint exists. Do not modify inspected source repositories.

Shared API in `core.py`: `SkillError`, `require(condition,message)`, `decimal(value)` strict finite Decimal rejecting booleans, `utc(value=None)` aware UTC datetime (None=now), `iso(value=None)`, `digest(obj)`, `Workspace(root)` with `read(kind)` returning envelope, `write(kind,data,inputs=None,now=None)` returning envelope; `config` property. Inputs dict is `{artifact_kind: artifact_digest}`. Envelopes: schema_version=1, kind, created_at, inputs, data, digest. `Workspace.lock()` context provides exclusive state mutation lock. Data JSON numeric prices/quantities stored decimal strings. Inputs validation is ownership module's responsibility. Root CLI dispatches module `run(args)`; Namespace attributes documented below.

Config keys: mode='paper'; symbol='BTCUSDT'; venue='fixture' or 'binance'; product_type='spot' or 'linear_perpetual'; quote_currency='USDT'; initial_cash='10000'; fee_rate='0.001'; slippage_bps='5'; risk_budget='25'; max_notional='2000'; max_total_exposure='4000'; max_daily_loss='100'; risk_ttl_seconds=30; max_market_age_seconds=120; signal_ttl_seconds=300; qty_step='0.00001'; price_tick='0.01'; min_notional='5'; max_spread_bps='30'; stop_pct='1'; target_r='2'; lookback=20; min_rvol='0'; source_urls=[]; source_min_interval_seconds=60. Limits are explicitly fictional demo settings. Normal init requires caller config for trade limits, no implicit personal allocation. Perpetual execution fails closed unless real required margin/funding contracts are implemented; research comparison allowed with honest limits.

Market `data`: symbol, venue, product_type, interval_seconds, as_of (ISO UTC), bars list[{time(ISO UTC open),open,high,low,close,volume(decimal strings),closed(bool)}], bid,ask, metadata{qty_step,price_tick,min_notional}, health{valid(bool),gaps(list),closed_bars(int)}, source{mode:'fixture'|'import'|'public_rest',...}. Source market input JSON has same data shape. Reject unknown/missing units/invalid/gapped data rather than infer it. News input {items:[{id,title,url,published_at(optionalISO),source,assets:list}]}. News outputs includes items, source_health, checked_at; consumed separately, no news action forces trades.

Trade module `trade.py` owns run(args), commands entry,plan,size,risk,paper. `args.workspace`, `args.now` (optionalISO), `args.command`, `args.action` (paper 'submit'|'close'), `args.price` (paperclose optional decimal), `args.side` ('long'|'short', defaultlong). Other fields None unless provided. Artifact names proposal,plan,sizing,risk,orders,portfolio,ledger. Entry uses lagged closed-bar breakout lookback, explicit waiting state, optional min_rvol; use last close then paper fill at ask+adverse slip (not same close). Plan supports long; short only for research perps and not paper execution unless qualified. Risk binds current config/market/plan/sizing/portfolio digests, account state and TTL; recomputes Decimal risk/filters before paper submit, atomically revalidates under lock. Paper ledger idempotent, no real approval or network call. Return JSON envelope; CLI errors nonzero. Paperclose can use args.price fixture but must label manual hypothetical mark, apply fees, enforce inventory and idempotency. Invalid/new upstream state invalidates old downstream artifacts.

Market module `market.py` run(args): command market; args.input JSON path or args.fetch bool, args.symbol(optional), args.limit int, args.interval ('1m'|'5m'|'15m'), args.now optionalISO. Explicit public REST fetch only, no order URLs. Source errors produce failure with old artifact unusable. News module `news.py` run(args): args.input or args.fetch, args.now; config source_urls explicit allowed HTTP(S) public feeds; bounded bodies/timeout, reject private network URLs/credentials/redirects, respect min interval, conditional requests/source health and durable ID/version dedupe. No paid providers or hidden auth.

Research module `research.py` run(args): command backtest,simulate,world. args.workspace,now,seed(default19),replays(default10000),agents(default10000),steps(default20),block_size(default4). Read market and config; simulate reads plan; status insufficient_data if unavailable. Backtest explicit chronological next-bar fills+fees/stop gaps/stopfirst ambiguity, singleposition, inventory/cost ledger or documented research-only results. Simulate contiguous blocks seedreproducible, 24/7 no NYSE clock; conditional outcomes not calibrated probabilities; no independent10k observation claim. World actual lightweight synthetic participant order submission and finite-volume matching with ledger accounting; not MiroFish/OASIS or10000realpeople. Resource caps enforce. Outputs backtest,simulation,world with inputdigests, assumptions, metrics, limits. No network/LLM.
