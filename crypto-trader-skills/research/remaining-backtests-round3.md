## Reading and reproduction

Win rate uses strictly profitable closed trades or lots after the cost basis named in the column. A completed replay with zero closes has blank win rates. The drawdown columns use the realized equity path and the initial capital recorded by the corresponding engine. The price-only, fee-only and all-cost P&L columns are reconciled separately. Where funding is modeled, the all-cost value adds signed funding. Pine charts generally use the common 10,000 USDT initial equity, 5.9 basis points per side in fees and 3 basis points per side in modeled execution charges, with separately marked input overrides.

The research scripts and JSON manifests record pinned code hashes, input archives, replay settings, results and residual dependencies. Pine and native untrusted code ran in offline isolation. The changed workbook ranges preserve historical rows, the original sheet layout and native table filters. Delta Demo entry stayed paused throughout this study.

The remaining dependencies include native FMZ deployment settings and market state, legacy Pine compiler failures, historical order queues and quotes, and missing protocol or signal inputs.
