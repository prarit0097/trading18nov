# Round 7 historical FMZ Python replays

This pass recovered published FMZ settings and an archived Python spot dependency for strategies with previously unresolved orders or inputs. The results use BTC/USDT and ETH/USDT Binance spot history in the September 23–October 21 and October 21–November 4, 2026 study windows. The report contains separate BTC, ETH and combined rows for each window. These were historical simulations with no account connection.

## Source and execution

- The native worker ran the pinned public Python broker inside the existing offline AppContainer. Each recorded run binds the archived source, prepared code, broker, matched public settings and market tape to checksums. The finalizer checks positive volume at the recorded order times and reconciles simulated cash and inventory using reported filled quantities and average prices.
- IDs 705, 2465 and 2519 use the archived Python spot template. The public template preview matches the archive, including the EMA and taking-liquidity limit-order defaults. The Python 2 migration updates exception and type syntax. Number 2465 uses the archive's `TA.EMA` option, recovered from the public dropdown. [FMZ Python spot template](https://www.fmz.com/strategy/21104)
- Starting inventory follows the archive for ID 693 (one base coin and 10,000 USDT) and the archived starting cash for ID 5304 (1,000 USDT). ID 2519 uses a labeled 50% starting inventory scenario to exercise the inventory-based sizing. Other native cases start with 10,000 USDT and no inventory. Starting equity is reported alongside native rows because these capital bases affect comparisons.
- ID 486 retains its twenty-minute polling. ID 2453 uses the source's minute records. IDs 705 and 5304 use a one-minute sampled decision loop in place of their faster original outer loops. ID 5304 uses a fresh in-memory state per run and receives no external commands. [FMZ storage documentation](https://www.fmz.com/syntax-guide/fun/storage), [FMZ backtest behavior](https://www.fmz.com/user-guide/backtesting-system/overview-and-starting-a-backtest)
- ID 4860 recreates the archived Turtle conditions using only completed daily candles, then tests at the next traded opening observation. The archived 20-day channel and 14-day ATR take precedence over later public defaults, and the matching public value supplies the 1% allocation. The daily variant labels its fill and slippage assumptions separately from a native broker receipt.
- ID 5670 preserves the archived seven-daily-bar grouping and hourly order price reference. The native study uses the pinned completed-day history and samples the original decisions every 15 minutes. Public documentation confirms the previous-bar boundary in `TA.Highest`. [FMZ indicator reference](https://www.fmz.com/lang/en/syntax-guide/fun/ta/ta.highest)

## Reading the results

The JSON `coverage` arrays identify accepted strategy IDs, explicit historical variants and any incomplete trial. Only accepted IDs contribute to `results`. See the per-feed `evidence` arrays for the settings and matching checksums. Win rates, P&L and drawdown use realized FIFO closes. The native history reports order creation timestamps, so their sequence is a proxy for exact fill chronology, especially for resting orders. Open inventory remains separate. The calculation uses 5.9 bps fees and a distinct 3 bps execution adjustment per side. When there are no completed entries and exits, there is no measured win rate. These figures describe the specified historical replays. [FMZ order structure](https://www.fmz.com/syntax-guide/struct/order)

Two archives illustrate why some native cases still require inputs. ID 575 has only a sell rule for existing inventory. Its author supplied a separate mode that starts with 10 BTC on the daily Bitfinex BTC/USD chart. Replays of that exit logic need to preserve the inventory and label any venue or market substitution. ID 4681's published price ceiling is zero, so it cannot enter on a positive ask. A meaningful replay needs a substantive ceiling and valid historical quotes accepted by its buy adapter.
