# Non-FMZ catalogue replay

The workbook contained 231 pending non-FMZ IDs. The [replay manifest](nonpine_replay.json) lists all 231 and includes six result rows per completed ID. The rows cover BTC, ETH and both markets combined in each of the two existing IST windows. Venue, market, interval, source and P&L model are attached to the rows.

- Reference runs from 23 September through 20 October 2026 IST. Later runs from 21 October through 3 November 2026 IST. Binance candles were complete at one minute for both assets on spot and USDT-margined perpetuals, with August history for warmup. Higher timeframes use complete UTC-aligned bins inside the windows. The manifest records public archive addresses and verified SHA-256 digests. [Binance public data](https://github.com/binance/binance-public-data)
- The isolated native Freqtrade 2026.10 replay retained the pinned strategies' configured entry, ROI, stop, custom exit and timeout rules on their source intervals. The model starts with 10,000 USDT and uses 1,000 USDT stakes, two open positions and the native OHLC execution rules. Costs are 5.9 bp per side inside the broker and an additional 3 bp per side of realized turnover in reported net. Those are standardized study assumptions. Closed trades reconcile against native output. Forced terminal closes count as unsettled. Perpetuals use isolated 1× margin, historical funding observations and mark candles with an explicit modeled maintenance tier. Depth, queue, order latency and market impact were outside the replay. The native result is a screen and has no dedicated prefix-by-prefix lookahead validation. [Freqtrade fill assumptions](https://www.freqtrade.io/en/stable/backtesting/#assumptions-made-by-backtesting)
- TradingView uses PineTS 0.13.1, 15-minute Binance perpetual prices and the OHLC broker path. The five published scripts use the published order rules, including the intraday risk rules. BarUpDn retains 10% equity sizing and the other cases use 1,000 USDT. Ten documented rule reconstructions add explicit parameter choices in `tradingview_methods`. They reverse on the next open after the opposite signal. The PineTS rows use fees and an ex-post estimate for spread and slippage. They exclude perpetual funding and leverage/liquidation cash flows. [TradingView built-in strategies](https://www.tradingview.com/support/folders/43000587406/)
- Jesse 3.6.1 uses its research broker with pinned strategy callbacks, 1-minute source bars and source-controlled risk sizing on separate 10,000 USDT books per market. The route interval defaults to 15 minutes when the source omits one. The test uses the native 5.9 bp commission, estimates extra spread/slippage at 3 bp per side and leaves funding outside the perpetual scenario. Jesse positions closed in the last minute are conservatively counted as unsettled. [Jesse research backtest](https://docs.jesse.trade/docs/research/backtest)
- Deribit returned public historical trade prints and a current list of combinations. The catalogue describes structures. An executable historical test still needs contract selection and entry/exit rules plus a synchronized combination or leg quote record. Hummingbot and OctoBot were screened for controller/evaluator inputs, order configuration, depth and execution-state dependencies. The protocol rows list the product-specific rule and data needs per ID. [Deribit Combo Books](https://support.deribit.com/hc/en-us/articles/31424954956061-Combo-Books) · [Hummingbot backtesting](https://hummingbot.org/dashboard/backtest/)

Drawdown is realized cumulative USDT P&L from a 10,000 USDT base. Both-coin Freqtrade rows come from a single two-market simulation. Both-coin TradingView rows combine independently simulated markets. A tested row without closed trades has no win-rate denominator. The study made no changes to the demo processes or ledgers.

## Reproduce

Use a dedicated scratch directory outside the repository containing only public data and code. Install Node 24, Python 3.13, `beautifulsoup4` and `openpyxl`. Place the offline PineTS 0.13.1 package under the scratch directory with lifecycle scripts disabled. The Windows sandbox runs Python from a scratch copy of the base interpreter and standard library at `python/python.exe`, plus dedicated package directories. It has no network capabilities. The verified isolation probe could write to scratch, while external connections and reads from the trading project and user documents returned `PermissionError`.

```powershell
python -m research.nonpine_inputs $scratch
uv pip install --target "$scratch/deps" 'freqtrade==2026.10' 'ccxt==4.5.93' 'pandas==3.1.1' 'numpy==2.5.5' 'TA-Lib==0.8.3' 'technical==1.7.0'
uv pip install --target "$scratch/freq-addons" --no-deps 'ta==0.11.0'
Copy-Item research/nonpine_freqtrade.py, research/nonpine_sandbox.ps1 $scratch
& "$scratch/nonpine_sandbox.ps1" -Root $scratch -Script 'nonpine_freqtrade.py' -Argument 'all' -TimeoutSeconds 900
python -m research.nonpine_tradingview $scratch
node --permission --allow-worker --allow-fs-read="$scratch" --allow-fs-read=research/nonpine_tradingview_worker.mjs research/nonpine_tradingview_worker.mjs "$scratch/tv-candidates.json" "$scratch/tv-candles.json" "$scratch/node_modules/pinets/dist/pinets.min.es.js" 4 > "$scratch/tv-binance-variants.jsonl"
python -m research.nonpine_coverage $scratch $baselineWorkbook research/nonpine_replay.json
```

Use the baseline workbook from commit `6803fb14cb7c0e66d1e9e2408e9531310d56bce5`. The Freqtrade run can be restarted in shards by passing an alphanumeric label followed by catalogue IDs. The report assembler uses `freq-all-out.jsonl` for a standalone rerun and accepts the original run and shard outputs. The inspected source archives stay in scratch. If a public data checksum changes, the input script stops before the replay.

For Jesse, copy `nonpine_jesse.py` into scratch and install Jesse 3.6.1 and its research dependencies into `jesse-deps`. The entry script loads the native research broker and ML imports used by the strategy base class, bypassing eager imports of the unused Ray-based Monte Carlo package. Run the copied script with the same no-network AppContainer launcher. Its output is `jesse-out.jsonl`. The original archive stays untouched. The KDJ retry maps the removed `self.capital` alias to `self.balance` as specified by Jesse's exception.
