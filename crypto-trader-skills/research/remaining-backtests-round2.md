## Additional Pine execution and data

- The fill-recalculation pass enables PineTS's historical `calc_on_order_fills` path only when the source explicitly requests it. A fixed-price fixture verified that a stop activates immediately after the entry fill and closes on the same candle, while the normal bar-close model exits later. This broker emulates an OHLC path. Recalculation can see completed bar values, which may expose intrabar lookahead. Its results are labeled **FMZ · Intrabar OHLC**. [TradingView strategy execution model](https://www.tradingview.com/pine-script-docs/concepts/strategies/)
- The market-data pass retains a 15-minute chart and uses confirmed 1-minute and 3-minute Binance futures references, alongside the previously supported same-market intervals. The independently archived 1-minute files match the published checksums in the asset manifest. Immutable chart symbol aliases can be inlined when every use is a direct request argument. Quotes are admitted only under a verified OS sandbox where the outbound networking and private-file probes both fail.
- The **Confirmed variant** delays an unsafe higher-timeframe request to its close. Existing confirmed offsets are preserved. This intentionally changes when the input becomes visible. The logic is screened on the same public price windows so its behavior can be observed without using future bars. [TradingView request and lookahead semantics](https://www.tradingview.com/pine-script-docs/concepts/other-timeframes-and-data/)
- The **Capital override** variant interprets a single unconditional literal wallet assignment as initial account equity. It verifies that broker state or orders do not precede that assignment, moves the value into the broker configuration, and computes percentage drawdown relative to that equity. The original value is recorded in the result row. [FMZ strategy settings](https://www.fmz.com/doc/9293)
- The **Clock snapshot** variant fixes historical evaluation time at the shared archive cutoff of 4 November 2026 00:00 IST. Calls that rely on realtime script state remain governed by the original eligibility checks. A clock-dependent variant measures the stated snapshot. [TradingView time variables](https://www.tradingview.com/pine-script-docs/concepts/time/)

The Binance USD-M replays use the Reference and Later IST dates established in the first pass. Unless a group uses different documented engine settings, fee-only P&L deducts 5.9 basis points per side. The all-cost estimate also models 3 basis points per side of spread and slippage. Pine drawdown uses realized closed-lot cash movements and a starting reference of 10,000 USDT or the stated literal equity. Scripts requiring exchange queues, platform-only templates or synchronized unavailable feeds retain those dependencies.

## Reproduce the additional Pine trials

Use the same pinned FMZ ZIP and Binance archive directories identified in [the first round](remaining-backtests.md). Export the previously unresolved records from `remaining-backtest-coverage.json` as an object keyed by catalogue ID. Run `python -m research.fmz_intrabar_replay prepare ARCHIVE BACKLOG FIVE_MIN_DATA ONE_MIN_DATA WORK`. Use `--causal-only`, `--capital-only` or `--clock-only` to reproduce the explicitly labeled variants. Use `--isolated` only in a verified no-network process sandbox. Run the repository's isolated `delta_pinets_worker.mjs` against the emitted candidates and candles. Save its JSON lines as `out.jsonl` and run `python -m research.fmz_intrabar_replay finalize WORK OUTPUT`.

Timed-out feed and variant candidates receive a second run at the same inputs and settings with a 50-second candidate budget. A previously successful candidate is preserved. The deterministic execution and isolation receipts are saved separately from market results. [Fixture checks](fmz-intrabar-validation.json)

Deribit results use historical atomic combo prints and the trade sizes, fees, conversion basis and fill experiment described in the non-FMZ report. Native FMZ runs use public source settings, with market metadata and exact balance reconciliation described by their engine reports. Demo order entry stays paused throughout this offline study.
