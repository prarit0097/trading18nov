# FMZ #5211 partial take-profit and trailing reservation evidence

FMZ saved this Pine v4 strategy with a BTC USD-M perpetual, a daily chart and a 1h base from 15 December 2022 through 21 December 2023, end exclusive. The source itself requests the historical last 5m observation for each daily decision. It sizes entries at 100% of USD equity, declares 0.07% commission, sells 20% at a 1% take-profit and places a separate trailing exit on the same entry ID. The strategy uses a filtered MACD and MFI long signal plus an ATR-based market-close condition. [FMZ source](https://www.fmz.com/strategy/436221)

The literal legacy series/series RSI overload stops Pine Compat compilation. The compatible run substitutes TradingView's algebraic identity for that single legacy overload and preserves the strategy settings and calls. The staged feed contains 371 daily bars and 106,848 checksum-verified 5m bars per BTC/ETH market. Daily OHLC from the archived 1h base agrees with the 5m aggregates. The sampled close, price source, typical price and volume agree on every chart bar. A full 5m feed and the terminal-only control agree across the first seven days. USD calculations use the pinned Coinbase prior-day USDT-USD close. [Legacy RSI overload](https://www.tradingview.com/pine-script-docs/migration-guides/to-pine-version-5/#removed-an-rsi-overload) [Historical lower-timeframe requests](https://www.tradingview.com/pine-script-docs/concepts/other-timeframes-and-data/#lower-timeframes) [Binance public archives](https://github.com/binance/binance-public-data)

The compatible broker reports two full trailing closes per market and no TP1 fill. The named TP1 control alone exits one out of five units at 105. Appending the author's full named trail makes Pine Compat replace TP1 and exit all five at 120. Placing the trail first, then TP1, gives one at TP1 and four at the trail. The engine source routes a full trail through replacement rather than the multi-reservation append branch. Both pinned Piner backends exit all five at 105 in the isolated 20% control, so they cannot independently corroborate the quantity. TradingView's reservation documentation treats quantity reserved by one exit as unavailable to the others. [TradingView partial and multi-level exits](https://www.tradingview.com/pine-script-docs/v5/concepts/strategies/#partial-and-multi-level-exits)

On the real feeds, suppressing the trail solely as a diagnostic produces a first 20% BTC exit of 7.543 at 26,773.90 and a first 20% ETH exit of 125.501 at 1,609.24. The first verified 5m candles with prints at or above these grid-protected limits start at 2023-06-19 18:00 UTC and 2023-09-28 02:00 UTC, respectively. The ETH diagnostic removes a trail that otherwise exits the position earlier, so this print shows sensitivity to the exit policy. It does not imply the source position survived until TP1. The candle evidence does not verify queue priority or an FMZ-host fill.

The catalogue retains one Pending disposition and contributes no performance rows. A compatible broker must verify named partial reservation, the effect of reissuing the trail and TP1, and first-touch chronology before this strategy can contribute win rate, P&L or drawdown.

## Reproduce

1. Use the pinned FMZ source document from commit `7853bb2bf262c4567ac238d3552d97f0e50cb801` as `source-5211.md`. Each original source digest, market file and FX response is identified in the evidence JSON.
2. Run `python -m research.fmz_round38_5211_stage HOURLY_ARCHIVES FIVE_MINUTE_ARCHIVES COINBASE_FX APP_CONTAINER_ROOT` from the project root. Keep all raw inputs in local scratch.
3. Copy the runner and reservation fixture into the existing R13-compatible Windows sandbox with the pinned `pine_compat` binary and its existing `replay_2864` and `probe_1216` support. Run both Python scripts in AppContainer. Keep the existing no-file/no-network isolation receipt.
4. Copy the bounded `5211-reservation.json` fixture and the alternate script into the isolated Piner directory. Run it against both backends of the pinned 0.13.0 package. Keep its existing isolation receipt.
5. Run `python -m research.fmz_round38_5211 APP_CONTAINER_ROOT PINER_ROOT OUTPUT_JSON`. Repeating this final check with the same evidence yields identical bytes.
